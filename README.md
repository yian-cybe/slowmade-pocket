# 慢慢造物

一本送给盘成勤的手机手作记录本。普通浏览器即可使用，无需注册、ChatGPT 或 GitHub 登录。代码和网页由 GitHub Pages 托管；照片、文字和草稿只保存在使用者自己的手机浏览器中。

## 日常记录

1. 新建一件作品，写下名字和材料。
2. 点开作品，添加过程照片与文字。相册和直接拍照都可用，照片会压缩到最长边不超过 1800 像素，每条最多 12 张。
3. 下次接着记录。已保存的过程可以修改，输入中的草稿会自动保留在本机。
4. 完成后写心得，标记为已完成。灵感可单独收藏。

第一次打开要联网下载应用。离线缓存成功后，无网也可打开和记录。浏览器或系统禁止缓存时可能无法离线启动；本地记录和离线应用缓存分开存储，应用更新不会主动清空记录。

## 放到手机桌面

- iPhone：在 Safari 中打开，点分享 → 添加到主屏幕 → 添加。
- 安卓：在 Chrome 等浏览器的菜单中选择安装应用或添加到主屏幕。
- 微信内收到链接：先在菜单中选择用浏览器打开。

建议安装后从桌面图标开始正式记录。部分苹果系统版本可能把浏览器与独立应用的数据分开；如需要迁移，先导出备份，再在桌面应用中导入。

## 备份和换机恢复

首页、底部都有“备份与恢复”。导出的 JSON 文件包含所有已保存的作品、过程文字、照片与灵感；未正式保存的草稿不在备份中。请确认文件已保存在手机文件目录或安全的外部位置。文件包含私密照片，请只交给可信任的人。

在另一台手机用同一网站打开“从备份文件恢复”，选择备份文件即可。导入会替换当前的作品和灵感，操作前有确认提示；先完整校验文件与照片，再在一个数据库事务里恢复，文件损坏或版本冲突不会部分覆盖原记录。单个导入文件上限 300MB。

**清除浏览器网站数据、卸载浏览器、丢失手机，都可能导致本机记录丢失。GitHub 和网站服务器没有你的照片副本。请定期导出备份。** 无痕模式不适合长期记录。浏览器会被请求给予持久存储，但最终是否批准由浏览器决定，不能代替备份。

## 维护

- `npm ci` 安装锁定依赖。
- `npm run typecheck` 检查类型。
- `npm test` 检查本机保存、并发冲突、照片备份恢复和损坏文件保护。
- `npm run build` 生成完整静态网站到 `dist/`。
- `npm run dev` 在 `http://127.0.0.1:5178/` 预览已构建版本。

默认分支 `codex/mobile-notebook` 的更新经过 GitHub Actions 检查后自动发布。网页中的图片没有外部请求依赖。不要改仓库名称、GitHub Pages 地址或域名，除非先提醒使用者导出备份；浏览器本地存储按网址来源隔离，换域名不会自动带走数据。

称呼和生日信在 `app/notebook-app.tsx`，手作插画在 `components/craft-art.tsx`，页面样式在 `app/globals.css`，本机存储和备份逻辑在 `lib/storage.ts`。
